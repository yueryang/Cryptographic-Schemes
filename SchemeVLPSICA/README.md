## SchemeVLPSICA

This is the category of the proposed VL-PSI-CA cryptographic scheme. 

### SchemeVLPSICA

- ``SchemeVLPSICA.py``: This is the official implementation of the VL-PSI-CA cryptographic scheme in the Python programming language based on the Python Charm-Crypto framework. 
- ``SchemeVLPSICA.java``: This is the official implementation of the VL-PSI-CA cryptographic scheme in the Java programming language based on the JPBC library.
